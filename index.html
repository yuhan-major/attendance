👩‍🏫 선생님 처음 시작하기
  1. 이름·비밀번호 확인: 화면 맨 위 내 이름 버튼 → [내 계정]에서 이름과 비밀번호를 바꿀 수 있습니다. 관리자가 정해준 초기 비밀번호는 꼭 바꾸세요.
  2. 우리 학과 학생 확인: [학생 명단] 탭에서 학번·이름·학과가 맞는지 보고, 틀리면 칸을 눌러 바로 고칩니다. (학과 교사는 자기 학과 학생만 보입니다)
  3. 가입 승인: 학생이 직접 회원가입하면 [학생 명단] 위쪽 "가입 승인 대기"에 뜹니다. 확인 후 [승인]을 누르세요.
  4. QR 인쇄·부착: [출결 & 전체공지 → 3. QR 인쇄]에서 우리 학과 교실용·교무실용 QR을 인쇄해 붙입니다.
  5. 학생 안내: 처음 비밀번호·PIN은 본인 학번입니다. 첫 로그인 때 꼭 바꾸게 하세요. 아직 안 바꾼 학생은 명단에 🔐가 붙습니다.
  6. 매일 확인: [출결 & 전체공지] 맨 위 실시간 현황판에서 미등록 학생을 확인합니다.

진로진학부·상담·교감 선생님(전체 조회)은 모든 학과를 볼 수만 있습니다. 위쪽 [학과] 선택으로 학과별로 나눠 보세요.

📚 반 관리 전공심화반과 따로 운영하는 반(방과후 남는 반 등)을 [반 개설]로 만들고, 반마다 학생·출결 QR·시간·운영일·전달 사항을 따로 관리합니다. 자세한 내용은 아래 "반 개설·관리"
👥 학생 명단 엑셀처럼 칸을 눌러 바로 수정(자동 저장). 연락처는 마우스를 올려야 보입니다. [학생 추가], [PIN/비번] 초기화, [삭제], [명단 CSV]. 위쪽에 가입 승인 대기 학생이 뜹니다.
✅ 과제 ('다했니') [+ 새 과제 출제] → 학생이 [다했어!]를 누르면 제출 인원이 올라가고, 미제출 학생 이름이 보입니다.
🎯 취업 로드맵 학년별로 묶어서 목표 기업·자격증·출석률·NCS 기준 달성률을 보여줍니다. 목표 기업·자격증은 [학생 명단]에서 고치면 반영됩니다.
🔔 학과 공지 & 메모 학과 공지는 우리 학과 학생·선생님만 봅니다(메뉴 아래 띠에도 표시). 메모장은 나만 보는 메모로, 캡처 이미지를 Ctrl+V로 붙여넣을 수 있습니다.
📅 학사일정 & NCS 학사일정 등록·D-day 확인. NCS 모의시험 불참 횟수를 −/+ 로 조정하면 2회 이상은 "취업추천 제외"로 표시됩니다.
💼 채용 공고 [+ 공고 등록] → 기업명·구분·핵심 요약을 올리면 모든 학생이 봅니다.
✅ 처음 운영 시작 체크리스트

위에서부터 순서대로 하시면 됩니다.

  1. 관리자 비밀번호 변경: 화면 위 내 이름을 누르면 언제든 바꿀 수 있습니다.
  2. 교사 계정 추가: 아래 [교사 계정 관리 → + 교사 추가]에서 학과별로 학과부장과 담당 선생님을 추가합니다.
  3. 학생 명단 확인: [학생 명단] 탭. 3302 김영진은 원래 명단에 학과가 비어 있어 자동화시스템과로 임시 등록했습니다.
  4. 운영일 지정: [출결 탭 → 2. 운영일]에서 0교시와 방과후 각각 [이번 달 평일 일괄 운영]을 누르고, 공휴일·시험일은 날짜를 눌러 해제합니다.
  5. 학교 좌표 저장 (학교에서): 휴대폰으로 이 사이트에 접속 → 아래 [📍 현재 위치 가져오기 → 좌표 저장]
  6. 시험해 보기: 아래 [테스트 모드 켜기] → 오른쪽 아래 🧪 시연 설정으로 출석을 시험 → 끝나면 꼭 끄기
  7. QR 인쇄: [출결 탭 → 3. QR 인쇄] → 학과별로 교실용·교무실용을 인쇄해서 붙입니다.
  8. 학생 안내: 처음 비밀번호와 PIN은 본인 학번입니다. 첫 로그인 때 꼭 바꾸게 하세요. 아직 안 바꾼 학생은 명단에 🔐가 붙습니다.

📚 반 개설 · 관리 (방과후 남는 반 등)

전공심화반과 따로 운영하는 학생 묶음을 반으로 만들어, 반마다 학생 · 출결 QR · 시간 · 운영일 · 전달 사항 · 통계를 따로 관리합니다.

  1. [반 관리] 탭 → [반 개설]: 반 이름, 출결 방식(입·퇴실 / 입실만), 요일별 시간을 정합니다. 만든 선생님이 담당 교사가 됩니다.
  2. 학생 넣기: [+ 기존 학생 추가]로 명단에서 고르거나, 전공심화반이 아닌 학생은 [+ 새 학생 등록]에서 "이 반 전용"으로 등록합니다.
  3. 운영일 지정: 반 화면 오른쪽 달력에서 [운영 요일 일괄 지정] → 쉬는 날은 눌러서 해제
  4. 출결 QR 인쇄: [🖨️ 출결 QR 인쇄] → 반마다 QR이 다르니 그 반 장소에 붙입니다.
  5. 전달 사항: [+ 전달 작성] → 그 반 학생과 담당 선생님만 봅니다.
관리할 수 있는 사람그 반 담당 교사(여러 명 지정 가능, [👩‍🏫 담당 교사])와 전체 관리자. 전체 조회 선생님은 보기만
반 QR로 출석그 반 학생만 가능. 다른 반·전공심화반 QR과 섞이지 않습니다
"반 전용" 학생전공심화반 명단·0교시/방과후 통계·가산점에 나오지 않습니다. 반 화면에서 PIN 초기화도 할 수 있습니다
학생 화면[내 반] 탭에서 반 시간표·오늘 출결·전달 사항을 보고, [출결 & 전체공지] 탭의 내 출결 기록에도 반 출결이 같이 나옵니다

반을 삭제하면 그 반의 출결 기록·전달 사항·운영일이 지워집니다 (학생 계정은 남음).

📱 학생 출석 방법
  1. 교실(또는 교무실)에 붙은 QR을 휴대폰 기본 카메라로 비춥니다.
  2. 출석 화면이 열리면 학번 + PIN 4자리를 입력합니다.
  3. 휴대폰 GPS로 학교 반경 안에 있는지 확인한 뒤 출석이 등록됩니다.

• 0교시와 방과후는 같은 QR을 씁니다. 시간에 따라 자동으로 구분되고, 학생이 직접 바꿀 수도 있습니다.

• 교무실 불참 QR: 병원·상담 등으로 빠질 때 교무실에서 스캔하고 사유를 입력합니다.

• 다른 학과 QR로는 출석할 수 없습니다.

• 처음 위치 권한을 물으면 반드시 [허용]을 눌러야 합니다.

🔒 일 마감 · 출결 기록 수정

• 일 마감: [출결 탭 → 2. 운영일] 달력에서 날짜의 🔓를 누르면 🔒 마감됩니다. 마감하면 학생이 더 이상 등록할 수 없고, 기록이 없는 학생은 무단불참으로 집계됩니다.

• 마감하지 않아도 날짜가 지나면 기록 없는 학생은 무단불참으로 집계됩니다.

• 기록 수정: [출결 탭 → 4. 통계] 표에서 학생 줄의 [기록 수정] → 날짜·구분을 고르고 상태를 바꿉니다. 마감된 날짜도 교사는 수정할 수 있고, 수정한 사람 이름이 기록됩니다.

• 실시간 현황판: 출결 탭 맨 위. 30초마다 자동으로 새로고침되고, 미등록 학생이 맨 앞에 보입니다.

🧪 테스트 모드

• 켜면 화면 오른쪽 아래에 🧪 시연 설정이 나타나, 가짜 날짜·시각·위치로 PC에서도 출석을 시험할 수 있습니다.

• 예) 날짜를 평일로, 시각을 08:20으로 → 0교시 정상 출석 / 15:30 → 방과후 입실 / 17:55 → 방과후 퇴실

• 켜져 있는 동안은 학생도 가짜 위치로 출석할 수 있으니, 시험이 끝나면 반드시 끄세요. 켜져 있으면 모든 화면 위에 빨간 띠가 보입니다.

• 시험하면서 생긴 출결 기록은 [기록 수정 → 상태: (기록 삭제)]로 지우면 됩니다.

학교 GPS 기준 좌표

유한공업고등학교: 서울 구로구 경인로 8. 기본값은 대략적인 좌표입니다.
정확하게 정하는 방법 2가지: ① 아래 칸에 구글 지도 좌표 붙여넣기 ② 학교에서 휴대폰으로 [현재 위치 가져오기]

좌표 복사하는 방법 보기
  1. PC에서 구글 지도에서 유한공업고등학교를 엽니다.
  2. 학교 본관 건물 한가운데를 마우스 오른쪽 버튼으로 클릭합니다.
  3. 뜨는 메뉴 맨 위의 숫자(예: 37.49253, 126.82371)를 한 번 클릭하면 복사됩니다.
  4. 위 칸에 Ctrl+V로 붙여넣으면 위도·경도가 자동으로 들어갑니다 → 아래 [좌표 저장]

휴대폰 구글 지도: 건물을 꾹 누르면 위쪽 검색창에 좌표가 나옵니다. 플러스 코드(예: 8Q98FRQC+7W, FRQC+7W), 지도 주소(URL), 37°29'33.1"N 형식을 붙여넣어도 됩니다.
